# 12 岁以下 · 版式：骨架固定，皮肤自选

输出是一张单页 HTML，手机竖屏优先。**行程票的骨架 ＋ 折叠分镜的叙事。**

**这一份只管骨架。** 皮肤从 `assets/styles.json` 里按客户诉求选一套（`cartoon` 卡通绘本 / `neon` 深底信息图 / `line` 线稿），默认 `cartoon`。换皮肤不改骨架，只改色板、描边、圆角、字体与动效。

## 一、首屏四件，必须在一屏内读完

| 位置 | 内容 | 示例 |
|---|---|---|
| 钩子标题 | 一句话动作，不是地名 | 先去馆里找一枚铜钱，再去山上吹一会儿风 |
| 副行 | 地点 ＋ 年龄 ＋ 同行人 | 深圳博物馆 → 莲花山 · 8 岁 · 2 位大人 |
| 四格 | 出门、先做什么、吃什么、到家 | 09:00 / 10:30 / 12:00 / 16:20 |
| 主菜贴纸 | 时间轴上标出主菜那一段 | 一枚贴纸，写「主菜 · 50 分钟」 |

## 二、版面顺序：票根 ＋ 分镜（与皮肤无关）

1. **票根头**：钩子标题 ＋ 副行，底部一排齿孔。
2. **四格速览**：四张卡片，粗描边，硬阴影。这是行程票的骨架。
3. **分镜时间轴**：每一站一块卡片，往下堆，逐块淡入。这是分镜的叙事。
4. **进去先找**：一整块亮色，像一张贴纸，必给。
5. **折叠区**：花多少、怎么约、下雨怎么办、想深入的话、哪几条没查实。
6. **备选**：只写四要素。
7. **页脚**：编号与日期，做成票根条纹。

**为什么这么合**：票根头给人「这是一张票」的第一印象，四格让人三秒读完关键时间，分镜让人愿意往下翻。单用票根太硬，单用分镜开头太散。

## 三、视觉规则

**描边、圆角、阴影**：读所选皮肤的 `shape` 段。
卡通用粗描边加硬阴影，霓虹用细线加发光，线稿用细线无阴影。同一份骨架换皮肤，版式位置不动。

**颜色**：读所选皮肤的 `palette`。状态永远靠同一套位置区分：主菜一格最亮，餐食一格次亮，其余中性。换色不换位置。

**字体**：读皮肤的 `type` 段。标题最多两行，正文行高不低于 1.7，时间与金额一律等宽。

**贴纸与装饰**：允许贴纸、胶带、票根齿孔。**每屏最多一处装饰**，不铺满。

**插画**：看皮肤的 `illustration`。卡通用 SVG 几何或单线手绘，线稿只描边不填色，霓虹不放插画改用图解。**任何皮肤都不画真人脸。**

## 四、动效

读皮肤的 `motion` 段。共同规矩三条：

1. 都只播一次，不循环。
2. 遵守 `prefers-reduced-motion`，关闭后只保留最终状态。
3. 不用装饰性动效。孩子会盯着它看，忘了看内容。

## 五、骨架

```html
<div class="sheet">
  <header class="stub">
    <h1>{{钩子标题}}</h1>
    <p class="sub">{{地点}} · {{年龄}} 岁 · {{同行人}}</p>
    <div class="perf"></div>
  </header>

  <div class="four">
    <div class="card"><span>出门</span><b>{{时间}}</b><small>{{车程}}</small></div>
    <div class="card"><span>先做什么</span><b>{{主菜时间}}</b><small>{{动作}}</small></div>
    <div class="card"><span>吃什么</span><b>{{午饭时间}}</b><small>{{店名}}</small></div>
    <div class="card"><span>到家</span><b>{{时间}}</b><small>{{车程}}</small></div>
  </div>

  <section class="panels">
    {{每一站一块卡片：时间、动作、一句说明、依据}}
  </section>

  <section class="find">
    <span>进去先找</span>
    <p>{{一件实物}}</p>
    <p>问她：{{一个问题}}</p>
    {{插画}}
  </section>

  <details><summary>花多少</summary>{{费用表}}</details>
  <details><summary>怎么约</summary>{{一条一个动作}}</details>
  <details><summary>下雨怎么办</summary>{{具体改成哪里}}</details>
  <details><summary>想深入的话（可选）</summary>{{行前与回家，或一行「这次不加准备」}}</details>
  <details><summary>哪几条没查实</summary>{{最多三条，含当周活动状态}}</details>

  <section class="alt">{{备选四要素}}</section>
  <footer>{{编号}} · {{日期}}</footer>
</div>
```

## 六、文案约束

- 句子不超过 18 字。
- 一句一动作，动词开头。
- 不用「精心」「优美」「寓教于乐」。
- 时间写 `09:00`。金额写「约 189 元」，未知写「未知」。
- 称呼用「你」，写孩子用「她/他」跟档案一致。
- **风格是视觉，不是语气。** 不论选哪套皮肤，都不写「小朋友们我们出发啦」。

## 七、自检

1. 首屏四格是否都在第一屏（手机 390×844）。
2. 标题是不是动作，不是地名。
3. 装饰是否每屏不超过一处。
4. 动效是否都只播一次，是否遵守减少动态偏好。
5. 有没有超过 18 字的句子。
6. 「哪几条没查实」是否标了当周活动的状态。

# 12–18 岁 · 版式：骨架固定，皮肤自选

输出是一张单页 HTML。桌面与平板优先，手机竖屏也要读得下去。

**这一份只管骨架。** 皮肤从 `assets/styles.json` 里按客户诉求选一套，默认 `neon`。骨架的重心不变：把路线交给他定。换皮肤只改色板、描边、字体与动效，不改结构。

注意：客户若给 12–18 岁选了 `cartoon`，不要退回低龄版的写法。卡通只换外观，议题、决定权、强度如实这三条照旧。

## 一、首屏三件

| 位置 | 内容 | 示例 |
|---|---|---|
| 标题 | 这一天在讲什么，不是地名 | 一天看三种城市：旧城墙、老厂房、正在修的河 |
| 右栏 | 年龄、同行人、日期、总强度 | 15 岁 · 1 位家长 · 全程 6.8 公里 |
| 四格条 | 出发、停点数、午饭预算、回家 | 09:30 / 3 个停点 / 120 元 / 17:00 |

「停点数」这一格是这一档的标志。它说明路线不止一种走法。

## 二、版面顺序

1. 标题 ＋ 右栏摘要（等宽体，右对齐）
2. 四格条（细线或描边分隔，靠位置区分，不靠大色块）
3. **路线示意图**（SVG，标停点与时间，非实际比例）
4. 左栏：三种顺序；右栏：约定、费用、要提前做的、天气、没查实的
5. 议题区（1–3 个）
6. 可选延伸
7. 底部双栏：为什么值得、备选

860px 以下改单栏，示意图保留。

## 三、路线示意图

用 SVG 绘制，不用外部地图服务。

必须标出：起点、每个停点的名字与时间段、返程点、停点之间的步行或地铁距离。

不标实际地理比例，图脚写一句「示意，非实际比例」。

停点色点用空心加细描边，只有午餐用实心强调色。不用图标库。

路线用一条细描边加一层低透明度的粗描边叠出「发光」，不用滤镜。

## 四、视觉与动效

全部读所选皮肤的 `palette`、`shape`、`type`、`motion`、`illustration`。

无论哪套皮肤，这一档的三条不变：

1. 数字、时间、距离、坐标一律等宽体。
2. 路线用 SVG 画，不用外部地图服务，图脚写「示意，非实际比例」。
3. 不做循环动效，遵守 `prefers-reduced-motion`。

皮肤为 `neon` 时额外注意：颜色只给细线、描边与状态点，**不做大块填充**；不加卡通贴纸与表情符号。

## 六、骨架

```html
<div class="wrap">
  <header class="top">
    <h1>{{标题}}</h1>
    <div class="meta">{{年龄}} 岁 · {{同行人}} · {{日期}} · {{强度}}</div>
  </header>

  <div class="strip">
    <div><span>出发</span><b>{{时间}}</b><small>{{地点}}</small></div>
    <div><span>停点数</span><b>{{数量}}</b><small>{{可否改顺序}}</small></div>
    <div><span>午饭预算</span><b>{{金额}}</b><small>{{边界}}</small></div>
    <div><span>回家</span><b>{{时间}}</b><small>{{车程}}</small></div>
  </div>

  <figure class="map">{{路线 SVG}}<figcaption>{{示意说明}}</figcaption></figure>

  <div class="cols">
    <div class="main">
      <h2>这条线交给你</h2>{{2–3 种顺序，每种写实际差别}}
      <h2>今天带一个问题回家</h2>{{1–3 个议题，每个带“去哪找线索”}}
      <h2>可选延伸</h2>{{检索方向，不写完成要求}}
    </div>
    <aside>
      <section><span>这次的约定</span>{{决定权与边界}}</section>
      <section><span>费用</span>{{分项与合计}}</section>
      <section><span>要提前做的</span>{{一条一个动作}}</section>
      <section><span>天气</span>{{趋势与替代}}</section>
      <section><span>没查实的</span>{{最多三条，含当周活动状态}}</section>
    </aside>
  </div>

  <div class="verdict">
    <div><h3>这一天为什么值得</h3>{{两个具体理由}}</div>
    <div><h3>备选</h3>{{四要素}}</div>
  </div>
</div>
```

## 七、文案约束

- 句子不超过 24 字。
- 不用「推荐」「最佳」「必去」这类评价词。
- 强度如实写：距离、爬升、无遮阴段。
- 称呼用「你」，不用「您」，不用「孩子们」。
- **皮肤是视觉，不是语气。** 不论深底还是浅底，都不写「硬核」「炸裂」「燃」，也不玩梗。

## 八、自检

1. 首屏是否给出日期与强度。
2. 示意图是否标了每个停点的时间段。
3. 是否给了 2–3 种顺序，并写出实际差别。
4. 决定权是否只有一样，边界是否写清。
5. 议题后面是否都写了「去哪找线索」。
6. 是否没有任何大块高饱填充与循环动效。

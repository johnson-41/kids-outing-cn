# 信源与核验

## 一、五层

| 层 | 信源 | 用来确认什么 |
|---|---|---|
| L1 | 场馆、主办方、政府、当地气象与海洋潮汐 | 日期、票价、准入、预约、管制 |
| L2 | 小红书、抖音、视频号、微博及可追溯真实体验 | 入口路况、排队、口味、踩坑 |
| L3 | 本地宝、本地生活编辑、活动聚合、发布日历 | 发现线索 |
| L4 | 地图商户、本地榜单、点评与实际复购 | 餐饮与配套 |
| L5 | 本地报纸与新闻媒体 | 新馆、活动背景、独立印证 |

每次按主题尝试相关层。**不装作所有层都已访问。** 读不到就记「未读」。

不是每项事实都要五层证据。

## 二、六个状态词

| 状态 | 判据 |
|---|---|
| **已核实** | 至少 2 层证据，证据根独立，内容确实支持 |
| **多源一致（未获官方页）** | 3 个以上独立次级来源说法一致，官方原始页打不开 |
| **官方已确认未交叉** | 只有一个官方来源，还没第二条独立证据 |
| **估算** | 自己加的缓冲、车程、人均 |
| **待核实** | 只有一个次级来源，或来源成色不明 |
| **未查到** | 查过，没有 |

「多源一致（未获官方页）」可信度高于单一「待核实」，但不能写成「已核实」。

## 三、冲突处理

### 同级官方互相冲突

例：官网写 8:30–19:00，政府问答页写 8:30–18:00。两个都是官方原始页。

取保守值：闭馆或停止入场取更早的，开馆取更晚的，票价取更高的，年龄门槛取更严的。

在可信度表写「两官方源冲突，按保守值排」，附上另一个值。

规则或票价冲突无法保守处理时（一个说免预约、一个说要预约），按「需要预约」准备，并请家长出发前自行确认。

### 次级来源 vs 官方

**以官方为准，直接丢弃次级来源，不取保守值。**

保守值只适用于「两个同级官方、都可信、只是口径不同」。用在次级来源上会凭空造出假约束。

实测反例：某市外地牌照限行，官方通告为「长江大桥全天禁行，四条过江通道仅工作日早晚高峰禁行」，某汽车百科写成「每日 7:00–19:00 禁外地车」。按保守值往严取，会得出「必须 7 点前出门」，把一条本来无障碍的路线改坏。正确结论是「目标日为周六、路线不过江，完全不受影响」。

### 两个次级来源互相冲突

两个都不作依据，标「未核实，以现场指引为准」。不挑一个写成事实。

判定顺序：先看是否同级官方 → 再看信息是否完整 → 都不满足就标待核实，并给家长一个出发前的自查动作。

## 四、五类陷阱

### ① 活动起止日与年份

先核年份：URL 路径日期、页面发布日期、正文里的「今天/昨日」。任一显示与目标年不符，整条弃用。

实测坑：搜某日天气，前一两年同月同日的气象稿，城市列表、格式、措辞与今年一模一样，只有年份不同，结论可能完全相反。

三态必须记下：**期内 / 期外 / 期限不明**。

只有主办方页面、官方票务在售页或官方公众号给出的起止日，才可判「期内」。多篇互抄「持续至 X 月下旬」算一个证据根，不作期限证明。

「延时开放」「临时调整」「暑期安排」这类词，先找适用日期区间。区间已过或找不到，按常规时段排。

期限不明且是主菜 → 降草案。

### ② 票价与第三方服务

先看这个价格来自场馆官方，还是平台的组合商品。

平台「预约票＋包团讲解」常见 398–599 元，场馆本体可能免费。

**「原价」可能是拼出来的**：三张夜场票加总被标成「单票原价 564 元」，用来把折扣做漂亮。只认官方页的单价与现售价。

门票含哪些必须逐项核。乐园全日票常不含水上项目。

票价只认官方。平台只当「有没有这个馆」的线索。

**官方声明未委托第三方代约或讲解时，平台上的代约、拼团讲解一律不作依据，不得推荐。**

### ③ 信源成色

问：这页有发布日期、作者、原文链接吗。

无日期 ＋ 无作者 ＋ 通篇「建议提前规划」式空话 ＋ 店名对不上地址 → 命中两条即弃用。不抄它的店名和价格。

### ④ 天气预报

先按城市锁定唯一主源。深圳用深圳市气象局「深圳天气」；其他城市用该市气象台或中国天气网城市页；全国预警用中央气象台。

主源与商业站冲突，以主源为准，不取平均，不并列。

同一主源不同发布时次结论不一致时，取最新时次并注明旧值。

时效分层：

- 目标日 0–3 天内：用具体温度、降雨、风力、预警，据此排正午室内与户外时段。
- 4–7 天：只写趋势，**必须同时给雨天替代**，不把晴天当既定条件。
- 7 天以外：不引用具体温度与降雨概率，只写该时节气候特征，注明「临近再确认」。

一城一源记在城市资料里，之后每周复用，不重新比源。

### ⑤ 商业演出与研学

判定：孩子是看表演而非动手；同一文案在多地多场次出现；主办方是文化传播公司而非场馆、学校或科研机构。

处理：可作晚间或雨天备选轻量项，标「商业演出，非深度参与」。不占主菜，28 天内不得出现第 2 次。

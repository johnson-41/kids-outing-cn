# 复盘：动画页面

按反馈生成一张单页 HTML，可连续播放。内容不是计划，是**已经发生的事**。

## 一、内容从哪来

三处：本次方案（地点、时间轴、主菜）、本次反馈（哪段最有反应、她问了什么）、知识库（当日日期、同行人）。

**不许写计划里没发生的事。** 备选、没去的停点，都不进页面。

## 二、页面结构

五段，按时间顺序播放：

1. **封面**：日期、地点、同行人、一句话标题。这一帧就是 JPG 的来源。
2. **路线**：实际走过的停点，标出时间。没去的划掉。
3. **主菜**：最有反应的那一段，用一两句写。
4. **她/他的话**：原话引用。
5. **收尾**：一句总结 ＋ 下次想看什么。

## 三、两套视觉

风格从 `assets/styles.json` 读，与方案保持同一套皮肤。**三套不是配色不同，是三种语言。** 出图与页面必须同皮肤，不各自挑。

### 皮肤 cartoon：手绘绘本页

像一页翻开的图画书，孩子自己也想再看一遍。

- 底色纸黄，卡片粗描边加硬阴影，圆角 18–28px。
- 允许贴纸、胶带、齿孔、手写体标题。每屏最多一处装饰。
- 插画位一张，单线手绘加平涂，可画动物与物品，**不画真人脸**。
- 五段依次淡入，每段 400ms，间隔 600ms；贴纸入场用弹性曲线 0.3s。
- 时间轴色点依次点亮，间隔 80ms。
- 有播放控制：重播、暂停。

### 皮肤 neon：情报卡

像一份夜间外勤记录，不像相册。

- 近黑底，铺极淡网格，细线描边框，四角十字标记。
- 全部字体等宽或几何无衬线；数字、时间、距离、坐标一律等宽。
- 不用色块填充，颜色只给细线、描边、关键数字和状态点。
- **禁止卡通插画。** 路线用 SVG 折线加一层低透明度粗描边叠出「发光」。
- 动效只有三处：路线描边跑一遍 600ms、关键数字从 0 涨到目标值 400ms、模块淡入 200ms。
- 标签用英文小写小字作装饰，例如 `FIELD LOG / OUTING`、`SITE`、`KEY MOMENT`、`QUOTED ON SITE`。中文仍是正文语言。

两套都遵守 `prefers-reduced-motion`，关闭后只保留最终状态。

### 皮肤 line：速写本页

白底黑线，安静克制，两档年龄都可用。

- 底色近白，正文深墨，只用一条强调色。
- 细线描边，方形为主，无阴影。手绘线条与斜线填充做层次。
- 插画只描边不填色，可以用斜线打暗部。
- 动效只有两处：线条自绘 700ms、模块淡入 200ms。

## 四、封面帧与 card.json

封面帧就是导出 JPG 的内容，字段固定：

| 项 | 说明 | 上限 |
|---|---|---|
| 日期 | 2026-11-01 周六 | — |
| 地点 | 全称 | 14 字 |
| 同行人 | 8 岁 · 2 位大人 | — |
| 标题 | 一句动作或一句原话 | 短题 9 字内一行，长题两行 |
| 一件事 | 最有反应的那段 | 14 字 |
| 原话 | 她/他当场的问题 | 22 字 |
| 站点 | 3–5 条，写成「时间＋动作」 | 每条 16 字 |
| 页脚 | 编号与下次想看什么 | — |

**封面帧固定 1080×1350（4:5）。** 页面与 JPG 都从这一份 `card.json` 渲染，不各自维护内容。

```json
{
  "date": "2026-11-01 周六",
  "place": "深圳博物馆 金田路馆",
  "companions": "8 岁 · 2 位大人",
  "title": "找了一枚中间有孔的铜钱",
  "one_thing": "在铜钱墙前站了十分钟",
  "quote": "为什么中间要留个孔",
  "stops": ["09:45 到馆", "10:30 跟讲解", "12:00 午饭 阿胖福建菜", "13:30 莲花山", "16:20 到家"],
  "next": "下次想看会动的机器",
  "plan_id": "FO-20261101-001",
  "age_band": "under12"
}
```

`age_band` 决定默认皮肤（`under12`→cartoon，`teen`→neon）。客户另选时写 `"style": "neon"`（或 `cartoon`、`line`），导出脚本优先读这个字段；命令行也可用 `--style cartoon|neon|line` 强制指定。

## 五、确认环节

生成页面后先给家长看，问一句：「这样可以吗，要改哪里。」

- 要改 → 只改被指出的字段，重新生成。
- 可以 → 进 `review/export.md` 导出 JPG。
- 不想导出 → 停在页面，记「已生成，未导出」。

**确认前不导出。** 导出的是家长认可的版本。

## 六、边界

- 不自动上传、不分享到任何渠道。
- 不收集照片，页面不放孩子正面照。
- 无网络也能打开，样式全部内联，不引外部 CDN。

# 复盘：导出 JPG

把确认过的封面帧导出成一张 1080×1350 的 JPG。

## 一、为什么不用截图

本机没有浏览器内核，HTML 截图不稳定。改用矢量渲染：脚本直接拼 SVG，再栅格化。

好处：不依赖浏览器，换机器也能跑，中文由系统字体渲染，尺寸永远精确。

代价：版面必须用 SVG 重画一遍，不能直接复用 HTML 的 CSS。所以 `review/animate.md` 规定页面与导出读同一份 `card.json`，避免两边内容不一致。

## 二、调用

```bash
python3 scripts/export_card.py <card.json> <输出路径.jpg>
```

可选参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--scale` | 2 | 渲染倍率，2 表示 2160×2700 再缩到 1080×1350 |
| `--quality` | 92 | JPG 质量 |
| `--font` | 自动 | 指定中文字体名，默认按顺序探测 |
| `--style` | 按 card.json | `cartoon` / `neon` / `line`，客户另选时用 |

退出码：0 成功，1 参数错误或文件不存在，2 渲染失败。

## 三、依赖

- Python 3.9 以上
- `cairosvg`（SVG 转位图）
- `Pillow`（转 JPG 与缩放）

缺失时脚本会打印一行安装命令并退出，不自动安装。

## 四、运行前检查

1. `card.json` 六个必填字段齐：日期、地点、同行人、标题、一件事、页脚编号。
2. 输出目录可写。
3. 系统有中文字体。脚本会先探测 `Noto Serif CJK SC`、`Source Han Serif SC`、`Songti SC`、`SimSun`，都没有就用默认字体并打印一行警告。

## 五、交付给用户

导出成功后：

- 给出文件路径。
- 说一句「已导出，1080×1350」。
- 不解释技术细节，不贴脚本输出。

失败时：说清哪一步失败（缺依赖、缺字段、字体缺失），给一条可执行的下一步。

## 六、状态词

已导出 / 未导出 / 失败。

失败必须写原因，不写「稍后再试」。

## 七、边界

- 不上传、不分享。
- 不覆盖同名文件，自动加序号。
- 不修改 `card.json`。
- 不带水印、不加生成工具的署名。

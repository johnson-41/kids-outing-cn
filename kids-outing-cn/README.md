# 全国溜娃

本地自用技能。全国范围，不绑城市。按年龄分两档写方案：12 岁以下走卡通绘本式，12–18 岁走深底信息图式。出行后收反馈并导出一张 JPG。

## 怎么用

装到本机技能目录后直接说「这周末带孩子去哪」或「杭州有什么活动」。第一次问四五个问题，之后每次都从 check 开始。

换城市不用重装。说清城市，技能按 `city/` 里的资料加载；该城没有资料时按 `core/sources.md` 现查，并建议补一份城市档案。

## 两层数据的关键差别

**规则不变，活动每周变。** 场馆开放时间一年查一次够了；当周有什么展、什么市集，只能临查。

所以 `city/` 只存「去哪找」，不存「有什么」。看到的活动一律标 `当周在办` 或 `期限不明`，期限不明的不进主菜。

## 文件

| 路径 | 作用 |
|---|---|
| `SKILL.md` | 入口：check 闸门、按年龄路由、三层数据 |
| `core/` | 判定内核，与城市和年龄都无关 |
| `core/sources.md` | 全国活动怎么查，查不到怎么写 |
| `young/` | 12 岁以下：引导、价值层、卡通绘本版式 |
| `teen/` | 12–18 岁：引导、价值层、深底信息图版式 |
| `review/` | 复盘回路：**反馈时机与三档惊喜**、收反馈、动画页面、导出 JPG |
| `assets/kids.json` | 12 岁以下参数与视觉令牌 |
| `assets/teens.json` | 12–18 岁参数与视觉令牌 |
| `city/` | 城市资料层。按需建：用到哪座城才建哪份，深圳已备一份 |

## 导出

```bash
pip install cairosvg pillow --break-system-packages
python3 scripts/export_card.py card.json out.jpg            # 按 age_band 自动选风格
python3 scripts/export_card.py card.json out.jpg --style neon
```

卡片三档，由反馈多少决定：`simple` 只有封面帧、`full` 加时间轴、`full_child` 再加孩子原话并署名。card.json 写 `"tier"`，或提供 `child_says` 自动升到第三档。

三套皮肤，**自选，与年龄无关**：`cartoon` 卡通绘本（纸黄、粗描边、贴纸感）、`neon` 深底信息图（近黑、网格、霓虹细线）、`line` 线稿（白底黑线、速写本）。输出 1080×1350。

风格按客户诉求选，未指定时按年龄取默认（12 岁以下 cartoon，12–18 岁 neon）。card.json 写 `"style"` 或命令行加 `--style`。

依赖系统装有中文字体。脚本自动探测，探测不到会警告，可用 `--font` 指定。
